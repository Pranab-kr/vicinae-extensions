# Vicinae Speedtest Extension Design Specification

## Overview
A lightweight, fast, local network speed test extension for the [Vicinae](https://vicinae.com) command launcher. It provides real-time download speed, upload speed, latency (ping), and jitter measurements using Cloudflare's globally distributed edge network (`speed.cloudflare.com`) without requiring external proprietary binaries, Python scripts, or system-level dependencies.

## Goals & Non-Goals
### Goals
- **100% Lightweight & Binary-Free**: Powered entirely by native Node.js streaming APIs within Vicinae's React runtime (`@vicinae/api`).
- **Real-Time Telemetry**: Live instantaneous speed readings (Mbps) calculated using rolling windows during active download and upload streams.
- **Accurate Latency & Jitter**: Multi-probe RTT measurements to determine minimum ping, average ping, and jitter.
- **Native Vicinae UX**: High-fidelity `Detail` view featuring dynamic progress indicators, colored status tags, metadata sidebar, and rich action controls.
- **Ephemeral Operation**: Privacy-first, zero disk footprint, running tests on-demand without logging history files.

### Non-Goals
- Third-party closed-source Ookla binary bundling.
- Background scheduled periodic testing or bandwidth graphing daemons.
- Persistent local database storage for historical results.

### Component Breakdown
1. **`src/engine/types.ts`**:
   - `SpeedtestPhase`: `'idle' | 'discovering' | 'ping' | 'download' | 'upload' | 'complete' | 'error' | 'aborted'`
   - `ServerMetadata`: `{ ip: string, asn: number, isp: string, city: string, country: string, colo: string }`
   - `PingResult`: `{ min: number, avg: number, jitter: number, samples: number[] }`
   - `SpeedResult`: `{ currentSpeedMbps: number, averageSpeedMbps: number, bytesTransferred: number, durationMs: number }`
   - `SpeedtestState`: Full snapshot of state emitted on progress ticks.

2. **`src/engine/utils.ts`**:
   - `formatSpeed(mbps: number): string`: Clean format with auto unit scaling (e.g. `142.5 Mbps`, `1.2 Gbps`).
   - `formatBytes(bytes: number): string`: Byte size formatter (KB, MB, GB).
   - `formatDuration(ms: number): string`: Formats elapsed time.
   - `calculateJitter(samples: number[]): number`: Computes mean difference between consecutive latency samples.
   - `renderGauge(current: number, max: number, width?: number): string`: Generates visual ASCII/Unicode bar (e.g., `[████████████░░░░░░░░]`).

3. **`src/engine/cloudflare.ts`**:
   - `runSpeedtest(callbacks, signal)`:
     - **Stage 1 (Discovery)**: `GET https://speed.cloudflare.com/meta`
     - **Stage 2 (Latency/Jitter)**: 8 consecutive `HEAD / GET https://speed.cloudflare.com/__down?bytes=0` requests.
     - **Stage 3 (Download)**: Chunked streaming GET requests (`/__down?bytes=...`), calculating throughput every 100ms via chunk delta over time delta.
     - **Stage 4 (Upload)**: Streaming HTTP POST requests (`/__up`) with generated byte buffers, measuring upload throughput.
     - Full cancellation support via `AbortSignal`.

4. **`src/hooks/useSpeedtest.ts`**:
   - Encapsulates React state (`state`, `isTesting`, `error`).
   - Handles auto-start on mount and exposes `start()`, `cancel()`, `reset()`.

5. **`src/index.tsx`**:
   - Renders `@vicinae/api` `Detail` component with markdown overview and `Detail.Metadata`.
   - Binds `ActionPanel` keyboard shortcuts:
     - `Enter`: Re-run test
     - `Ctrl+C`: Copy formatted markdown report
     - `Ctrl+Shift+C`: Copy raw JSON
     - `Ctrl+X`: Cancel active test

## Error Handling & Resiliency
- **Network Failures**: Caught and rendered with friendly error state and immediate retry button.
- **Timeouts**: Individual test phases are bound by AbortSignal timeouts (15s limit per phase) preventing infinite hangs.
- **Clean Abort**: Component unmount or user cancellation halts all in-flight network sockets immediately.

## Testing Strategy
- **Unit Tests**:
  - `utils.test.ts`: Conversion algorithms, rate calculations, jitter math, ASCII gauge rendering.
  - `cloudflare.test.ts`: Mocked server interactions, streaming callbacks, error scenarios, and abort signal propagation.
- **Engine Verification**: Vitest unit testing executed with `npm test`.
